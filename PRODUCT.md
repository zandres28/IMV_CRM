# Nexum CRM

## Register

product

## Platform

web

## Users

ISP administrators and office managers who run daily operations — client onboarding, billing, network monitoring, technician dispatch, and administrative configuration. The interface serves desk-bound staff managing multiple workflows in parallel across a single-org deployment.

## Product Purpose

All-in-one ISP management. One platform that replaces the patchwork of legacy tools with a unified system for clients, billing, network monitoring (MikroTik/RouterOS), technician dispatch, service orders, and administrative control. Success means an ISP admin can run every daily operation from a single logged-in session without switching between four different tools.

## Positioning

All-in-one ISP management — clients, billing, network inventory, and field operations in one place. The claim every screen reinforces: everything your ISP needs to run, in one interface.

## Brand Personality

Professional, reliable, and modern. The interface communicates competence and trustworthiness — this is a tool for serious operators, not a flashy startup product. Tone is direct, confident, and efficient. Emotionally, the user should feel in control: the system is predictable, responsive, and never surprising.

## Anti-references

Clunky legacy ISP software. Avoid the dense, cramped, visually noisy aesthetic of traditional ISP admin panels — too many borders, too little whitespace, inconsistent controls, and confusing navigation. The interface should feel clean and modern without sacrificing the information density these users need.

## Design Principles

**Data density without chaos.** ISP admins work with rich, interconnected data — client records, billing history, network topology, service statuses. Every screen should pack real information into a clean, scannable layout. Favor structured tables, clear hierarchies, and visual rhythm over white-space-for-its-own-sake.

**Clarity over cleverness.** Every screen should be immediately understandable. Use standard UI patterns, predictable navigation, and obvious actions. The best interaction is the one the user can perform without thinking.

## Accessibility & Inclusion

WCAG 2.1 AA minimum. Keyboard-navigable data tables, sufficient contrast on metrics and status indicators, and focus indicators throughout. No motion dependencies for core interactions.
